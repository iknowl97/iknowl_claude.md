# LEARNINGS — დაჭერილი შეცდომები -> მუდმივი წესები

ვერიფიკაციის ციკლი (Verification Loop) მხოლოდ მაშინ არის ეფექტური, თუ ყოველი დაჭერილი ხარვეზი გარდაიქმნება მყარ, მუდმივ კორექციად (DURABLE correction) — წინააღმდეგ შემთხვევაში აგენტი ერთსა და იმავე შეცდომას დაუშვებს.
თითოეულმა ჩანაწერმა უნდა აღწეროს: რა იყო შეცდომა, რა წესი შემუშავდა მის შედეგად და რომელი Prior განახლდა.
როდესაც ეს ფაილი გაიზრდება, მთავარი წესები გადაიტანეთ `CLAUDE.md`-ში ან `.claude/rules/forbidden.md`-ში, ხოლო დანარჩენი დააარქივეთ.
